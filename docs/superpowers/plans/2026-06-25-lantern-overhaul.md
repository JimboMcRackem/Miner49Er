# Lantern Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace placeholder lantern visuals (circles + flat yellow tint) with a proper PixelLab sprite and a smooth radial amber glow, and make holding a lantern extend the carrier's fog-of-war vision radius by 2 tiles.

**Architecture:** Three independent changes: (1) Core simulation adds `LanternVisionBonus` to `EffectiveVisionRadius` when the miner holds a lantern; (2) WorldRenderer loads a new PixelLab lantern sprite and removes the old circle fallback; (3) WorldRenderer replaces the per-tile flat glow loop with a single `DrawTextureRect` per lantern source using a procedurally generated radial gradient texture.

**Tech Stack:** C#/.NET 8, Godot 4.6.3 .NET, PixelLab MCP (`create_1_direction_object` / `get_object`), xUnit.

```csharp
	private static ImageTexture BuildRadialGlowTex(int size = 128)
	{
		var img = Image.CreateEmpty(size, size, false, Image.Format.Rgba8);
		float half = size / 2f;
		for (int y = 0; y < size; y++)
		for (int x = 0; x < size; x++)
		{
			float t = Mathf.Clamp(new Vector2(x - half, y - half).Length() / half, 0f, 1f);
			float a = Mathf.Pow(1f - t, 2.5f);
			img.SetPixel(x, y, new Color(1f, 0.85f, 0.4f, a * 0.55f));
		}
		return ImageTexture.CreateFromImage(img);
	}
```
